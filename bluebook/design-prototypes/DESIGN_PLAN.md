# AI Agent蓝皮书版面设计提案

> 阶段：方向提案与样例页  
> 日期：2026-09-22

## 1. 设计技能调研

优先采用以下组合：

1. `anthropics/skills@frontend-design`：909K+安装，官方来源；负责独特视觉方向、内容驱动布局和避免模板化；
2. `jakubkrehel/skills@better-typography`：22K+安装；负责长文阅读、字号、行长、换行和字体细节；
3. 本地`awesome-design-md`：使用Stripe、Linear、Notion等设计系统作校准，不直接复制某一品牌；
4. 发布阶段再引入独立Web Accessibility审计。

不采用低安装量的“书籍编辑设计”Skill作为主导，因为其来源和验证度明显低于上述组合。

## 2. 推荐方向：Evidence Ledger

核心意象不是SaaS官网，而是“可信工程手册”：

- 像一本有批注、证据等级和架构图的技术专著；
- 保留纸张的沉静阅读感，但不用常见的米色+衬线模板；
- 以窄的“证据轨”作为全站记忆点：主张、实验、模式和版本始终有可追溯入口；
- 大标题不追求营销冲击，而强调章节编号和结构；
- 代码、ADR、风险与证据采用不同结构，不切成无差别圆角卡片。

### 视觉角色

- **正文**：长时间阅读，低刺激、高对比；
- **证据轨**：颜色编码证据、模式、实验和风险；
- **架构图**：主视觉，不增加无意义插画；
- **控制面板**：只出现在实验与模式页面，避免主册工具化。

## 3. 设计Token

### 色彩

| Token | 色值 | 用途 |
|---|---|---|
| Ink | `#10243E` | 标题、关键结构 |
| Text | `#26364A` | 正文 |
| Muted | `#65758B` | 元数据、辅助说明 |
| Paper | `#FCFDFE` | 阅读画布 |
| Mist | `#F2F6FA` | 导航和代码背景 |
| Cobalt | `#3157D5` | 链接、当前章节、控制 |
| Teal | `#058C82` | 已验证证据、成功 |
| Amber | `#C77912` | 条件、审批、注意 |
| Coral | `#D1495B` | 风险、失败、限制 |
| Violet | `#6857C8` | 模型、推理、模式 |

原则：不使用大面积渐变。颜色只表达语义，不作为装饰。

### 字体

- 中文正文：`Noto Serif SC` / `Source Han Serif SC`，18px，行高1.85；
- 中文标题与UI：`Noto Sans SC` / `Source Han Sans SC`；
- 英文与数字：`Inter Variable`；
- 代码：`JetBrains Mono`；
- 正文最大行长：68ch；
- H1：clamp(42px, 5vw, 68px)，字重650；
- H2：32px，H3：23px；
- 正文段间距0.9em，不使用两端对齐；
- 标题`text-wrap: balance`，导语`text-wrap: pretty`。

### 空间与形状

- 8px基础网格；
- 阅读页最大宽度1440px；
- 左目录248px、正文680–760px、右证据轨260px；
- 正文与侧栏间距48–64px；
- 功能元素圆角4–8px；
- 章节封面可使用大尺度几何切片，但卡片不统一套圆角和阴影。

## 5. 页面模板

### A. 首页

一个记忆点：在首屏用“确定性代码 → 有界Agent → 多Agent”横向光谱表达本书立场。避免常见大渐变Hero。

### B. 章节阅读页

三栏但不拥挤：左侧书目录、中心长文、右侧证据轨。滚动时只让左右辅助栏固定，正文自然流动。

### C. 模式卡详情页

采用“工程蓝图”布局：左侧Context/Problem，中心Solution结构图，右侧Forces和Exit Criteria；窄屏按阅读顺序折叠。

### D. 实验图谱页

不是普通Dashboard。采用目录表+证据色条；默认显示实验问题和证据状态，数字结果只有进入详情后出现。

## 6. 交互

- `Cmd/Ctrl + K`全局搜索；
- 章节阅读进度只用1px顶部线；
- 术语首现可展开定义，默认不弹Tooltip干扰阅读；
- 证据编号点击后右轨定位，不跳离正文；
- 架构图支持全屏和下载SVG/Excalidraw；
- 代码块支持复制、换行和查看原始文件；
- 只在目录切换和证据定位使用短动画；尊重`prefers-reduced-motion`。

## 7. 响应式

- ≥1200px：三栏；
- 800–1199px：目录抽屉+正文+窄证据轨；
- <800px：单栏，证据轨变成正文内可折叠块；
- 移动端正文17px以上，所有交互目标44px；
- 表格默认横向滚动，并提供卡片式语义摘要。

## 8. 样例页

本目录提供4个静态样例：

- `index.html`：设计方向总览；

## 9. 暂不做的事

- 不在方向确认前改写正式MkDocs主题；
- 不把每段内容包装成卡片；
- 不加入无意义3D、玻璃拟态、粒子背景或滚动特效；
- 不直接复制Stripe/Linear/Notion品牌；
- 不把实验未验证状态隐藏在视觉层级中。

## 10. 决策结果

已确认：

1. 接受“Evidence Ledger / 可信工程手册”作为正式方向；
2. 中文正文采用衬线体，UI与标题采用无衬线体；
3. 首页增加现代技术出版物的视觉张力；
4. 109张实验图谱纳入首发站点。

正式决策记录见`../plan/DECISIONS_DESIGN.md`。下一阶段进入正式MkDocs主题与发布构建，不再停留在方向探索。
