# 来源与许可证政策

## 1. 基本规则

- 所有复用的文字、图片、表格、代码和数据均登记来源。
- 学习结构和思想后采用原创表述，不复制大段原文。
- 修改第三方内容时注明“基于……修改”。
- 不确定许可证的资产不得进入发布版本。

## 2. 两个仓库

- `ai-agent-book`：以根目录 LICENSE 为准，同时检查第三方子项目。
- `ai-agents-for-beginners`：以根目录 LICENSE、NOTICE、商标条款及具体文件说明为准。
- Microsoft 产品名、Logo 和截图仅作案例，遵守商标规范，不暗示官方背书。

## 3. 资产处理

| 资产 | 首选处理 |
|---|---|
| 概念 | 原创综合并引用来源 |
| 长段文字 | 不直接复制，重写并引用 |
| 代码 | 最小必要摘录，标注许可证和来源 |
| 图片/图表 | 优先依据事实重新绘制 |
| 产品截图 | 核验使用条款、版本和日期 |
| 外部论文图 | 优先重绘，并引用论文 |

## 4. 发布门禁

每个外部资产必须具备：来源 URL/路径、作者或组织、许可证、使用方式、修改说明、核验状态。
