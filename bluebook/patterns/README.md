## 模式卡门禁

每张模式卡必须包含：

1. Context：问题发生的环境；
2. Problem：需要解决的矛盾；
3. Forces：质量、成本、延迟、安全等作用力；
4. Solution：结构和运行机制；
5. Consequences：收益和代价；
6. Failure Modes：错误应用方式；
7. Implementation Sketch：厂商中立伪代码或图；
8. Evidence：章节、实验卡或外部标准；
9. Exit Criteria：何时不再使用该模式。
