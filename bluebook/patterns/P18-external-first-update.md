# P18 外部能力优先更新

> 状态：Release Candidate 1  
> 主要章节：第12、13章

## Context

系统表现不足，需要改进。

## Problem

直接训练参数昂贵、慢且难回滚，许多问题来自知识或控制。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
按知识→Prompt/Skill→程序/Harness→模型参数选择最可控载体。
```

## Consequences

### 收益

更快、更可解释和可回滚。

### 代价

外部组件增多带来版本协调。

## Failure Modes

用训练修复时效知识或权限；规则无限堆积。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

## Evidence

- 蓝皮书章节：第12、13章；
- 实验卡：按具体实现绑定，不以代码存在替代运行证据；
- 外部标准：涉及协议或安全标准时在发布前核验版本与日期。

## Exit Criteria

充分上下文和接口下仍稳定失败且有数据/验证器时进入训练。

## Checklist

- [ ] 问题与作用力真实存在。
- [ ] 有更简单方案基线。
- [ ] 失败模式可测试。
- [ ] 权限、预算和恢复已定义。
- [ ] 收益覆盖新增复杂度。
