# P04 类型化状态与显式终态

> 状态：Release Candidate 1  
> 主要章节：第3、9章

## Context

长任务跨节点、进程和事件运行。

## Problem

聊天历史无法可靠表达业务状态、所有权和完成语义。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
使用版本化State Schema；终态区分成功、部分成功、阻塞、失败、取消和预算耗尽。
```

## Consequences

### 收益

可恢复、测试和审计。

### 代价

Schema演进和迁移增加工程工作。

## Failure Modes

把Model停止生成当作成功；状态只存在内存。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

## Evidence

- 蓝皮书章节：第3、9章；
- 实验卡：按具体实现绑定，不以代码存在替代运行证据；
- 外部标准：涉及协议或安全标准时在发布前核验版本与日期。

## Exit Criteria

单次无状态调用无需持久运行状态。
