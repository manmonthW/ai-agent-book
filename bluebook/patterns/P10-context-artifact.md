# P10 上下文压缩与Artifact外置

> 状态：Release Candidate 1  
> 主要章节：第4、7、9章

## Context

长任务积累网页、日志、代码和历史。

## Problem

完整重放导致溢出、成本和干扰。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
按丢弃、抽取、摘要、外置顺序缩减；大型载荷存Artifact并在上下文传URI、Hash和相关片段。
```

## Consequences

### 收益

控制上下文规模，保留可追溯原文。

### 代价

摘要可能丢信息，Artifact需要权限和生命周期。

## Failure Modes

摘要覆盖原证据；每轮重复粘贴大型内容。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

## Evidence

- 蓝皮书章节：第4、7、9章；
- 实验卡：按具体实现绑定，不以代码存在替代运行证据；
- 外部标准：涉及协议或安全标准时在发布前核验版本与日期。

## Exit Criteria

上下文短且所有细节关键时不压缩。
