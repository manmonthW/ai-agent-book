# P09 稳定前缀与动态轨迹

> 状态：Release Candidate 1  
> 主要章节：第4章

## Context

多轮Agent希望复用缓存并减少上下文漂移。

## Problem

时间戳、工具重排和动态信息混入前缀会降低稳定性。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
把政策、工具和固定说明置于稳定前缀；运行状态、观察和用户信息放动态尾部。
```

## Consequences

### 收益

提高可预测性并可能增加缓存复用。

### 代价

需要版本化前缀；供应商缓存机制不同。

## Failure Modes

为了最新信息每轮重写System；承诺固定缓存收益。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

## Evidence

- 蓝皮书章节：第4章；

## Exit Criteria

单轮短请求或不支持缓存时收益有限。
