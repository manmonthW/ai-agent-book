# P11 权限感知RAG

> 状态：Release Candidate 1  
> 主要章节：第5、11章

## Context

知识库包含多租户或分级内容。

## Problem

先召回后过滤可能泄漏标题、向量或内容。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
索引时绑定Tenant和ACL；检索前按Principal过滤；输出保留来源和权限。
```

## Consequences

### 收益

降低跨租户泄漏并支持审计。

### 代价

过滤可能降低召回，索引更新更复杂。

## Failure Modes

把权限写进Prompt；召回后让模型决定能否展示。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

## Evidence

- 蓝皮书章节：第5、11章；
- 实验卡：按具体实现绑定，不以代码存在替代运行证据；
- 外部标准：涉及协议或安全标准时在发布前核验版本与日期。

## Exit Criteria

公开知识库无需用户级ACL，但仍需来源治理。
