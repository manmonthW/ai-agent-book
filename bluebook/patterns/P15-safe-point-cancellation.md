# P15 Safe Point与级联取消

> 状态：Release Candidate 1  
> 主要章节：第8、9、14章

## Context

运行含子任务、工具和物理/外部副作用。

## Problem

立即杀死可能留下半完成状态，不传播取消会产生孤儿任务。

## Forces

- 质量与正确性；
- 延迟与成本；
- 安全与合规；
- 运维与可恢复性。

## Solution

```text
在一致状态设置Safe Point；取消先阻止新工作、保存状态、清理资源并沿任务树级联。
```

## Consequences

### 收益

可控停止和恢复。

### 代价

某些阻塞工具无法协作取消，需要超时和强杀。

## Failure Modes

只停止UI输出；取消父任务但Worker继续。

## Implementation Sketch

实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。
