## B. 证据等级

- E0：编辑综合或待验证主张；
- E1：设计、伪代码或静态材料；
- E2：代码与运行说明存在；
- E3：有运行结果摘要，但原始证据不完整；
- E4：真实运行、Artifact、版本和限制可复核；
- E5：标准、权威来源或多源成熟证据。

实验卡中的等级是证据完整性，不是结果优劣。实验“通过”可仅表示协议执行完成，不表示假设成立。
