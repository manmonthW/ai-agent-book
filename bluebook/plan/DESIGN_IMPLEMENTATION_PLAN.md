# 正式版面设计实施计划

> 方向已确认：Evidence Ledger  
> 状态：Ready

## Phase 1：出版基础

- 建立蓝皮书独立`mkdocs.yml`；
- 建立发行内容清单，排除样章和模板；
- 设计站点导航：主册、模式、实验、附录；
- 建立自托管/可回退字体策略；
- 创建主题Token和基础布局。

门禁：本地可构建、无断链、桌面/移动导航完整。

## Phase 2：首页与全局壳层

- 将首页升级为现代技术出版物；
- 实现自主性光谱、读者路径、篇章导航和证据总览；
- 实现全局搜索、主题切换和版本入口；
- 控制动效，支持Reduced Motion。

门禁：首页不呈现SaaS模板感；Lighthouse与键盘导航达标。

## Phase 3：长文阅读

- 实现左目录、正文、右证据轨；
- 设置中文衬线正文、无衬线UI和代码字体；
- 完成图、表、代码、Callout、脚注、术语和上下章导航；
- 响应式降级为移动单栏。

门禁：正文60–75字符行长、字号≥17px、无水平溢出。

## Phase 4：模式手册

- 模式目录支持按问题、风险和生命周期浏览；
- 模式详情采用工程蓝图布局；
- Forces、Consequences、Evidence和Exit Criteria形成固定视觉语法。

门禁：20张模式卡均可导航，语义结构不依赖颜色。

## Phase 5：实验图谱

- 109张实验卡纳入首发；
- 实现章节、主题、证据等级和验证状态筛选；
- E3、E4、零事件、待审查状态明确；
- 实验详情链接回章节、模式和Artifact。

门禁：筛选可键盘操作，URL可分享，未审查状态不可被误认已验证。

## Phase 6：发布质量

- 深色模式和打印样式；
- WCAG对比度与无障碍审查；
- 外链、SEO、Open Graph和404；
- HTML、PDF和EPUB一致性；
- RC截图评审和跨浏览器验证。

门禁：发布清单完成并签署。
