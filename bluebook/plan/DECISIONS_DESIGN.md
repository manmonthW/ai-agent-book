# ADR-008：数字出版视觉方向与信息架构

- 状态：Accepted
- 日期：2026-09-22
- 决策者：内容负责人

## Context

蓝皮书已完成RC1内容冻结，需要确定正式数字出版物的视觉方向、中文正文排版、首页气质及实验图谱是否进入首发站点。首轮已提供首页、章节、模式和实验目录样例。

## Decision

1. 采用“Evidence Ledger / 可信工程手册”作为正式视觉方向；
2. 中文长文正文采用衬线体，标题、导航和交互采用无衬线体；
3. 首页在严肃白皮书基础上增加现代技术出版物的视觉张力，但不使用无意义3D、粒子或装饰性玻璃拟态；
4. 109张实验图谱纳入首发站点，并明确展示证据等级与验证状态。

## Consequences

- 正式主题围绕“主册 + 模式 + 实验 + 附录”建立统一导航；
- 证据轨成为章节页的关键识别元素；
- 首页允许更强的排版尺度、结构动画和架构视觉，但正文保持安静；
- 实验图谱必须具备筛选、状态说明、深链接和移动端可用性；
- 发布构建必须同时验证长文阅读、无障碍、深色模式和图表。

## Guardrails

- 不直接复制Stripe、Linear、Notion或其他品牌；
- 不隐藏待审查、E3降级和零事件状态；
- 不将所有模块包装成相同卡片；
- 动效只用于状态变化、导航和证据定位；
- 正文行长、字号和行高优先于视觉密度。
