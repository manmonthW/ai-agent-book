# Architecture and Editorial Decisions

## ADR-001：采用一主两辅一附录

- **决定**：主册 + 模式手册 + 实验图谱 + 数字附录。
- **原因**：主文可读性与完整技术资产不可同时塞进单卷。
- **后果**：所有内容盘点时必须指定目标载体。

## ADR-002：主仓库为内容主干

- **决定**：`ai-agent-book` 提供核心概念和实验；`ai-agents-for-beginners` 提供入门表达、Planning、部署、安全和厂商案例。
- **原因**：前者体系和实验更深入，后者课程化与产品化内容更强。

## ADR-003：最低充分自主性

- **决定**：蓝皮书按“确定性代码 → 结构化调用 → RAG → Workflow → 有界 Agent → 多 Agent”组织架构选择。
- **原因**：避免把 Agent 当作所有 AI 应用的默认答案。

## ADR-004：不覆盖原书

- **决定**：新内容全部位于 `bluebook/`。
- **原因**：保留原始教材和翻译体系，便于来源追踪与差异审查。

## ADR-005：强主张必须登记

- **决定**：定量、时效性、高风险和因果主张进入 `claims.yml`。
- **原因**：避免过期信息和未经验证的营销性结论进入主文。
