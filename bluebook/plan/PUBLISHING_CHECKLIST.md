# 正式发布检查清单

> 目标：从“内容重构完成”推进到“可公开发布并可长期维护”。  
> 当前结论：尚未达到正式发布门禁；实时问题清单见`PUBLICATION_READINESS.md`。

## P0：必须完成

### 内容冻结

- [ ] 第0–14章和结语状态改为Release Candidate。
- [ ] 20张模式卡状态改为Release Candidate。
- [ ] 组合样章、章节模板、模式模板不进入公开导航与发行包。
- [ ] 主册目录移除旧样章状态描述。

### 引用与证据

- [ ] 建立完整参考文献库：作者、标题、年份、URL/DOI、访问日期、许可证、核验状态。
- [ ] 正文强主张使用编号引用或脚注，而非只写“主要来源”。
- [ ] 核验RFC 8785、RFC 8032、OpenTelemetry、ReAct、MCP、A2A等官方来源。
- [ ] 所有产品、模型、协议和时效性案例增加`as_of`日期。
- [ ] 决定109张实验卡是“完整证据附录”还是“仅收录已审查卡”；不得让读者误解其验证状态。

### 法律与版权

- [ ] 建立发行资产白名单。
- [ ] 默认仅发布8张原创架构图；任何其他图片逐项核验来源和许可。
- [ ] 补充`NOTICE.md`、许可证归属和第三方声明。
- [ ] 核验补充仓库内容的MIT归属要求。
- [ ] 核验商标、产品截图、论文重绘和代码摘录。

### 构建与元数据

- [ ] 建立蓝皮书独立`mkdocs.yml`和导航。
- [ ] 生成HTML站点。
- [ ] 生成PDF和EPUB，或明确首发只提供HTML。
- [ ] 添加`CITATION.cff`、`NOTICE.md`、`CHANGELOG.md`和版本号。
- [ ] 添加一条独立CI：链接、构建、图片、发布门禁和制品Hash。
- [ ] 发行包不依赖作者机器绝对路径。

### 人工审查

- [ ] Agent架构领域专家审查。
- [ ] 安全、隐私和治理审查。
- [ ] 中文专业编辑和校对。
- [ ] 无障碍审查。
- [ ] 法律/许可证审查。

- [ ] 深色模式检查SVG和代码块。
- [ ] 全部内部链接和外部链接检查。
- [ ] PDF目录、页码、图注、孤行、跨页表格检查。
- [ ] EPUB目录、字体、图片和代码块检查。
- [ ] 搜索、SEO、Open Graph、favicon和404页面检查。
